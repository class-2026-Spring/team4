# 🗺️ 전국 생활폐기물 재활용 비율과 제주 생활쓰레기

> 전국 지역별 쓰레기 현황을 시각화하고, 분리수거 배출 가이드를 쉽게 접할 수 있는 웹사이트입니다.

---

## 📌 주제 소개

대한민국 각 지자체의 재활용률 데이터는 공개되어 있지만, 일반 시민이 쉽게 접근하기 어렵습니다.  
또한 분리수거 방법이 지역마다 달라 혼란을 주는 경우도 많습니다.  
이 프로젝트는 공공데이터를 기반으로 **전국 시도별 재활용 현황을 시각화**하고,  
**올바른 분리수거 방법을 게임과 퀴즈로 쉽고 재미있게 익힐 수 있도록** 제작되었습니다.

---

## ✨ 주요 기능

### 🗺️ 전국 시도별 재활용 비율 지도
- 2024년 폐기물 발생량 기준 데이터 시각화
- 지역 선택 시 재활용 처리량 및 비율 상세 확인
- 재활용률 상위 8개 지역 순위 표시

### ❓ OX 퀴즈
- 분리수거 상식을 퀴즈 형식으로 학습
- 정답/오답에 따른 즉각적인 피드백 제공

### 🎮 분리배출 캐치 미니게임
- 60가지 쓰레기 아이템을 6개 분리수거함에 분류
- 숫자키 1~6으로 빠르게 선택 가능
- 5라운드마다 속도가 빨라지는 무한 라운드 방식
